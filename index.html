Stage 02 · 自动化任务

不用我刷，爆款自己来找我

灵感随录解决"我看到的"，自动化任务解决"我没看到的"。每周定时让 AI 去扫，把结果直接推到我飞书。

⏰ 每周爆款扫描

定时任务 · 到点自动跑
  • 小红书七日爆款笔记：近 7 天各垂类 TOP50 + 爆款共性
  • 小红书低粉爆款：粉丝 <5000 但互动 >500 的素人信号
  • 豆包工作 / 操作浏览器：抓抖音某品某月高赞帖，标题 / 链接 / 点赞收藏自动入表

📨 主动推送，不用惦记

豆包工作伙伴 · 主动智能服务
  • 每周一早上把上周爆款扫描结果推到飞书对话
  • 有关键群 / 关键人消息，主动提醒并起草回复
  • 每周四下午自动根据本周工作内容整理周报初稿发我过目
示例指令："每周一早上 9 点，帮我扫一下上周小红书护肤个护垂类的爆款笔记和低粉爆款，按内容方向归类，挑出 3 个可伶可俐吸油纸可以参考的选题，整理成一份飞书文档发给我。"
Stage 03 · 爆款改写 Skill

链接丢进去，脚本出来

把"我怎么写可伶可俐"这件事写成 Skill，AI 读到就按我的标准执行。这是整个飞轮里复用率最高的部分。

三个核心 Skill

都是我自己反复迭代出来的，不是一次写完的
  • 小红书文案仿写：丢一篇爆款笔记链接 → 出可伶可俐种草笔记（标题 / 正文 / tag）。锁死 3M 过油膜、奶瓶级 PP 等卖点；相似度 ≤70%；素人感、拒营销腔；支持按人群出 5 个差异化角度。
  • CNC 内容脚本策划：面向达人 brief 场景，按"好物分享 / 精致上班 vlog / 参考片改写"选范式，输出逐字口播稿 + 画面要求 + 达人选择标准。
  • 抖音爆款视频改写：输入美妆爆款挂链视频链接 → 四维拆解（口播 / 画面 / 情绪曲线 / 挂链策略）→ 按 80% 结构对齐 + 90% 文案差异化 仿写，保留钩子，每句话重写。
方法论：不是一次写完，是"拿真实案例试跑 → 发现问题改规则 → 删冗余 → 锁约束"反复 3-5 轮。尤其要把被否掉的方案也写进去（比如某条口播范式为什么不行），下次才不会重蹈覆辙。
Stage 04 · 内容 BF 生成

不用重新交代背景，
它读过我所有的历史 BF

这是豆包工作和飞书打通后最爽的一点——普通 AI 每次都要你重新讲产品机制，豆包工作直接读你飞书里的历史 BF、周会纪要、人群规划。

一次产出完整达人合作 BF

对话式生成，落到飞书文档
  • 第 1 页：合作须知与核心机制（产品、卖点、挂链机制、投放要求、内容底线）
  • 第 2 页：金字塔人群模型（精致控油党 / 强社交 / 精致男士 / 彩妆爱好者 / 约会人群 / 素颜懒人）
  • 第 3 页：可视化呈现要求（爆点画面、拍摄 TIPS）
  • 第 4 页起：每条内容方向的开头切入点、必提卖点、内容结构
示例指令："读一下我飞书里 Q3 达人合作 BF 和最近 3 周的周会记录，按上次的结构和语气，帮我起草 Q4 第一批 15 位达人的合作 BF 初稿，写完直接落成一篇飞书文档。"
注意：AI 产出是初稿，不是终稿。品牌底线、合规词、过油膜可视化画面这些硬规则由我本人最后把关，这也是公司红线——AI 产出人工审后再对外。

Stage 06 · 内容复盘 · 飞轮回流

每周的结论，写回 Skill

Tool Stack

这套飞轮背后，
其实是三个东西

🛠 豆包工作（独立 APP）

干活的主力
  • /操作浏览器：自己打开网页、抓数据、截图、下载资料
  • /应用生成：搭个人工作台（千川数据看板、灵感看板）
  • 读飞书文档 / 多维表格：甩链接就读，不用复制粘贴
  • 写回飞书：生成内容直接落成飞书文档，或在原文档里补充
  • Go 模式 / Plan 模式：跑任务用 Go，做方案用 Plan 让它反问我

👥 豆包工作伙伴

飞书里的专属 AI 同事
  • 像真同事一样住在飞书联系人里，对话、日程、文档都在它服务范围
  • 自然对话建 Agent：告诉它人设、职责、知识库，它就变成"灵谋"
  • 定时任务 / 主动监听：每周自动跑爆款扫描、每天早上推未读摘要
  • 工作记忆：越用越懂我的品牌口径和写作风格
  • 权限和我本人一致，企业数据不用于模型训练

📚 飞书双向打通

不复制粘贴，是真打通
  • 读：历史 BF / 周会 Wiki / 群聊记录 / 妙记 / 多维表格
  • 写：高亮块排版直接写进飞书文档，同事在线批注
  • 发：一键转发到指定飞书群，不用我再搬运
  • 安全：数据不出飞书，敏感操作需要我确认

How to Start

如果你也想跑起来，
这一周就够了

六步上手路径

1先装后建：把市场里现成的 Skill（文档处理、数据下载）装上，当天就省事

2挑一件每周重复、有明确输出格式的事做第一个 Skill（周报 / 种草文案），别一上来搞复杂的

3用真实案例迭代 3-5 轮，把"什么不行"也写进去

4在豆包工作伙伴里用自然对话建你的专属 Agent（像灵谋那样）

5接上飞书：从"复制粘贴给 AI"变成"甩链接给 AI"

6数据类工作先锁口径，再谈自动化；每周把结论写回 Skill

一句话总结：豆包工作在这套工作里的角色，不是"更聪明的聊天框"，而是一个可以训练、可以沉淀、可以分享的数字工作搭子——你教它一遍，它替你做一周，你的方法还能原样交给下一个同事。
